# Ideas

Every idea starts here, at the root, whatever it turns out to concern. It is stored in its original wording, together with a log of every question asked about it, by Claude or by the user, and the answers.

Status values: `captured` → `specifying` → `specified` → `planned` → `in-progress` → `done` (or `parked` / `rejected`).
Scope: `system` or the name of one app; decided by `/spec` (until then `TBD`).
