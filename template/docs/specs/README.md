# Specs

One folder per idea that is being built: `NNNN-slug/` holds `spec.md` (what and why), `plan.md` (how) and `tasks.md` (the steps). The number matches the idea in [../ideas/](../ideas/README.md) and is unique across the repo.

**Where a spec lives depends on its scope** (ADR-0011): specs that span several apps, or change libraries, a dataset contract, the base environment or repo tooling, live here in `docs/specs/`. Specs that concern one app only live in `apps/<app>/docs/specs/`.
